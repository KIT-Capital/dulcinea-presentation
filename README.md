# Dulcinea One

A nine-slide HTML presentation about Dulcinea One, hospitality ownership, Medellín, the proposed Buy Box, fund, owner benefits, and owner journey. It uses the supplied Dulcinea logos and the five-color palette selected in the Pantone Connect files.

## Open the presentation

Download or clone the repository and open `index.html` in a modern browser. The built file includes its styles, scripts, photographs, and SVG branding and works offline. No installation or server is required; image-credit links open external websites.

Use the previous/next buttons, Left/Right keys, or slide menu to navigate. Up/Down, Page Up/Page Down, and Space scroll through longer slides before advancing. Home/End jump to the first/last slide. Fullscreen is available where the browser permits it.

## Edit and rebuild

Edit the files in `src/` and the color values in `design/palette.json`, then run either command from the repository root with Node.js 18 or newer:

```sh
npm run build
```

```sh
node scripts/build.mjs
```

No package installation or third-party dependencies are required. The builder writes `index.html` and embeds the original SVG bytes without modifying the artwork. Keep the generated `index.html` in version control so the presentation can be opened directly.

## Files

- `index.html`: complete offline presentation.
- `src/`: editable HTML template, CSS, and navigation JavaScript.
- `scripts/build.mjs`: portable Node.js builder.
- `assets/images/`: the hospitality concept image and Medellín photograph.
- `brand/`: original supplied brand package, preserved without changes.
- `design/`: active Pantone palette, digital values, roles, and source evidence.
- `source-packages/Dulcinea_Logo_Package_Copper.zip`: original supplied copper brand archive.
- `ASSET-SOURCES.md`: image and brand provenance.
